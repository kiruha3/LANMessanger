# LAN Messenger

P2P-мессенджер для локальной сети и прямых подключений через интернет — без серверов, регистрации и облаков. Один portable exe: скачал → запустил → работает.

Интерфейс «Рабочее место»: верхняя панель с навигацией, слева список контактов с поиском, центр — чат, справа сворачиваемая панель сведений о собеседнике и подключении. Спокойный бирюзовый акцент, светлая и тёмная темы.

В версии 0.22.1 добавлена вкладка **«ИИ»** с локальным агентом Pi. С версии 0.22.2
Enter отправляет сообщение, Shift+Enter добавляет строку. Чат автоматически прокручивается
к новым сообщениям и потоковому ответу (0.22.3). Подключение
аккаунта/API-ключа, модель, ответы и действия — внутри мессенджера. Агент работает
в выбранной рабочей папке с правами пользователя; данные задачи отправляются выбранному
провайдеру. Если компонентов нет, текстовый чат на Windows x64 показывает кнопку
«Установить компоненты ИИ» рядом с полем ввода. Она загрузит и настроит Node.js, Pi
и Git Bash без консоли и прав администратора.
[Настройка ИИ](docs/ИИ.md).

Для картинок добавлены **AI Horde** (бесплатно, анонимно, с очередью),
**Cloudflare FLUX.1 Schnell** (10 000 neurons в сутки на Workers Free, нужен свой
Account ID и API-токен) и **«Совместимый API — картинки»** для Provod и других
Images API. Готовое подключение **«Картинки бесплатно — AI Horde»** с моделью
**Dreamshaper** входит в базовую конфигурацию, в том числе после обновления.
В новом чате нажмите **«Нарисовать бесплатно — AI Horde»** и опишите картинку:
ключ, регистрация и загрузка списка моделей не нужны. Существующее подключение
Horde сохраняется без дубля; другие настройки и выбранный аккаунт не меняются.
Cloudflare и совместимые Images API настраиваются отдельно под шестерёнкой.
Текстовому агенту можно написать «Нарисуй кота через AI Horde»: он подготовит
описание и вызовет модель картинок. В списке появится дочерний чат генерации,
а картинка вернётся в исходную переписку. По умолчанию используется бесплатный
Horde. Для каждого текстового аккаунта под шестерёнкой доступны **«image gen — аккаунт»**
и **«image gen — модель»**: выберите подключение картинок или смените провайдера,
если прежний перестал работать. URL и ключ задаются в самом аккаунте картинок;
пустая модель инструмента использует его модель. Изменения действуют со следующей
задачи. Другой аккаунт или модель можно также явно указать в запросе;
автоматического перехода на другой сервис при ошибке нет.
Агент также может сам запросить каталог моделей картинок: спросите, какие модели
доступны в выбранном сервисе. Если каталог не загрузится, сохранённый список
будет явно отмечен как возможный устаревший.
Можно попросить нарисовать одним описанием через несколько разных моделей:
до четырёх запросов отправляются параллельно, каждый в свою очередь сервиса.
Для каждой модели появляется дочерний чат, картинки с названием модели
возвращаются в исходный по мере готовности. Ошибка одной не блокирует остальные.
В списке чатов пульсирует индикатор работающей задачи; новый готовый результат
подсвечивается до открытия, ошибки отмечаются отдельно, остальные чаты серые.
Свежие сообщения и результаты поднимают ИИ-чат вверх внутри папки; давние чаты
остаются внизу. Открытие без новых сообщений не меняет порядок.
Правый клик по ИИ-чату → **«Закрепить чат»** держит его выше остальных внутри
папки. **«Открепить чат»** возвращает обычную сортировку; выбор сохраняется.
Horde ограничивает частоту новых запросов: приложение отправляет их с небольшим
интервалом, а затем независимо ждёт картинки каждой модели. Ответы 403/429
показываются как ошибки сервиса, без автоматического повторения запросов.
Агент получает очередь Horde до готовности картинки: место и оценку ожидания
в секундах. Он может повторно проверить статус и отменить свои картинки по
вашему условию, например «если очередь больше 100 секунд, не жди».
По вашей просьбе агент также задаёт вопросы другим текстовым агентам: в свободный
существующий чат или в новый с выбранной моделью. Ответ возвращается в исходный
чат. Занятые чаты и неотправленные черновики не перезаписываются.
Картинка появляется в чате и сохраняется в `ai-data/images`; её можно открыть,
скопировать или сохранить отдельно. Для генерации Pi не нужен. Бесплатность
Horde обеспечивают добровольцы; скорость и наличие исполнителей меняются.
При полном выходе приложение отправляет отмену заданий Horde и до пяти секунд
ждёт подтверждения. Если отмена не подтверждена, ID сохраняется для проверки.
Сворачивание в трей сохраняет работу; Images API без команды отмены могут
продолжить уже начатую генерацию на сервере.

С версии 0.23.0 справа внизу поля сообщения выбирается **модель**, рядом —
**шестерёнка настроек** с аккаунтами, подключением, размышлениями и промптами. Кнопка «Добавить
аккаунт» создаёт отдельное подключение со своим ключом или OAuth-входом, URL,
моделью и инструкциями. Прежнее подключение остаётся как «Основной». Настройки
и загруженные модели сохраняются отдельно; переключение доступно между задачами.
Каждый чат запоминает свой аккаунт и последнюю выбранную модель. При переходе
между чатами и после перезапуска они восстанавливаются; новый чат наследует
текущий выбор. Старые чаты сохраняют выбор при первом открытии после обновления.
Если у старого чата сохранены аккаунт и модель последнего запроса, они
восстанавливаются сразу. Чаты работают параллельно; остановка действует на
открытую задачу. По вашему запросу агент может найти и прочитать другие ИИ-чаты.
`ask_agent` с `wait_for_result: false` сразу возвращает `accepted`, `request_id` и `chat_id`; поздний ответ приходит отдельным уведомлением.
Правый клик по ИИ-чату → «Переименовать чат…». Агент также может переименовать
свой чат или чат своего непосредственного подчинённого по вашему запросу.
Картинки прикрепляются через Ctrl+V, перетаскивание или «+»; для их разбора
нужна модель с поддержкой изображений.
Поле начинается с одной строки и растёт до шести строк. Рабочая папка показана
внизу поля рядом с «Полный доступ»; полный путь — в подсказке. Во время работы в ленте
видно текущее действие, а над полем ввода появляется плашка «Уточнить сейчас» и «В очередь».
Квадрат останавливает агента. «В очередь» (также стрелка или Enter)
отправляет отдельное сообщение после завершения текущей задачи; до этого сообщение
видно в чате с пометкой «В очереди». «Уточнить сейчас» прерывает текстовый ответ,
сохраняя написанное, и продолжает в том же чате. Уже запущенный инструмент закончится
до применения уточнения.
Новые сообщения и потоковый ответ прокручивают чат вниз. Кнопка «Загрузить модели»
находится в настройках подключения.
Через «Добавить папку…» слева, путь внизу или настройки можно выбрать рабочую папку.
Слева проекты раскрываются в списки чатов с их количеством. Выбор чата переключает
папку агента; последний чат восстанавливается после перезапуска. При ошибке модели
появляются инструкция, что настроить, и кнопка открытия настроек.
Pi запускается без установки пакетов из `.pi/settings.json` рабочей папки;
потеря сессии больше не стирает видимую переписку, ошибка провайдера не выдаётся
за успешное завершение.

В настройках ИИ выбирается «С пояснениями» или «Без пояснений». По кнопке
«Инструкция…» можно изменить инструкцию каждого режима и вернуть стандартную.
Настройки сохраняются и действуют со следующей задачи. Полученный текст
показывается потоком до завершения команд; наличие пояснений зависит от модели/API.
Установщик включает корневые HTTPS-сертификаты и использует доверие Windows,
поэтому установка не зависит только от заполненности локального кеша сертификатов.

С версии 0.22.4 настройки подключения сохраняются автоматически. Галочка сохранения
API-ключа действует без отправки сообщения; результат сохранения виден в панели.
С версии 0.23.2 рядом с полем ключа кнопка «Показать / Скрыть» позволяет посмотреть и скопировать
введённый ключ. При смене аккаунта или провайдера и закрытии настроек ключ скрывается.
В JSON настроек ключ не записывается: без галочки он хранится до выхода,
с галочкой в Windows — в зашифрованном файле `api-key.dpapi` своего аккаунта.

В 0.22.5 лента ИИ адаптирована из [bb](https://github.com/get-bb/bb) на PyQt:
потоковый Markdown, размышления при поддержке провайдера, компактные действия с
раскрываемыми подробностями. Код bb используется по MIT; см. [уведомления](THIRD_PARTY_NOTICES.md).
С версии 0.22.6 раскрытые карточки используют общую прокрутку ленты; пустые строки
в конце ответа не растягивают сообщение.

С версии 0.22.7 в пустом чате есть инструкция подключения и справочник 28 моделей
по разделам с ценами из предоставленного каталога. Для «Совместимого API» укажите
URL и свой ключ, затем нажмите «Загрузить модели»: список доступных ID берётся
из вашего API. Если загрузка недоступна, ID можно ввести вручную.
Рядом с моделью можно выбрать уровень размышлений, включая высокий и очень высокий;
доступность зависит от модели и API, выбор сохраняется для следующего запуска.

С версии 0.22.8 у подключения по API-ключу есть кнопка «Отключить API-ключ»:
она удаляет введённый и сохранённый ключ. Выход из аккаунта Pi и отключение ключа —
отдельные действия; для совместимого API вход в аккаунт не показывается.

## Возможности

- **Обнаружение участников автоматически** (UDP broadcast в LAN) — список контактов по IP
- **Личные чаты** в интерфейсе «как в Telegram» (пузыри, тёмная/светлая тема)
- **Локальный ИИ-агент** — вкладка «ИИ», аккаунт или API-ключ провайдера, работа с файлами и командами, потоковый ответ, дополнения к активной задаче и «Остановить агента»; отдельная история и сессии
- **Плагины ИИ** — каталог встроенных инструментов, переключатели отдельно для каждого чата и карточки генерации со ссылкой на дочерний чат. Установка сторонних плагинов пока не поддерживается.
- **Связи агентов** — дерево дочерних чатов, стрелки в узком желобке без сдвига списка и отметка ожидания ответа. Кнопка «Связи» и карточки ведут к связанным сообщениям.
- **Ответы с цитатой и копирование**: выделите текст сообщения мышью и нажмите Ctrl+C (macOS: Cmd+C); двойной щелчок выделяет слово. Правый клик — «Копировать выделенное», «Копировать» всё сообщение или «Ответить» с цитатой. Работает в личных чатах и комнатах.
- **Статусы сообщений**: Отправляется → Отправлено → Доставлено → Прочитано (квитанция о прочтении в личных чатах)
- Подтверждение доставки отправляется после успешной обработки входящего сообщения; ошибка обработки не превращается в ложное «Доставлено».
- **Картинки по Ctrl+V** — скриншоты из буфера прямо в чат; клик по пузырю — просмотрщик на весь чат с зумом и перетаскиванием ЛКМ
- **Календарь**: личные и общие события с участниками, напоминания, синхронизация между узлами — вкладка в главном окне
- **Центр уведомлений** (колокольчик справа вверху): сообщения, напоминания, ошибки туннеля, алерты о версиях
- **Обновления**: стабильные Windows-релизы проверяются на GitHub через 20 секунд после запуска и каждые 6 часов, если уведомления о версиях включены. В настройках есть «Проверить обновления»; результат — в колокольчике. Соседи LAN также анонсируют версии. Новые установки включают уведомления; сохранённое отключение сохраняется. Старые exe нужно один раз обновить вручную.
- **Работа через интернет**: достаточно открытого TCP-порта у одной стороны — постоянное соединение устанавливает тот, кто может достучаться, дальше оба пишут по нему
- **RDP-туннель по кнопке**: удалённый рабочий стол через канал мессенджера, без проброса портов на стороне «клиента»; совместный сеанс (shadow) — не выкидывает пользователя
- **Сканер сети**: все устройства подсети (IP, hostname, MAC), по кнопке
- **История переписки локально** — один файл `history.db` рядом с exe, никуда не передаётся
- **Трей + всплывающие уведомления** при закрытом окне, тихий режим до перезапуска, автозапуск с Windows. Иконка LM в синем квадрате показывает красную отметку непрочитанных; подсказка разделяет сообщения и прочие уведомления, без двойного учёта. Галочка «Открывать мессенджер при новом сообщении» в настройках уведомлений восстанавливает скрытое/свёрнутое окно и открывает чат; по умолчанию выключена, учитывает тихий режим и мьют чата.
- **Фичефлаги** в настройках: RDP, совместный сеанс, сканер, ntfy-push, уведомления о версиях
- **Один exe** (~38 МБ), настройки в `settings.json` рядом — переносится папкой

## Быстрый старт

1. Скопируйте `LANMessenger.exe` на оба компьютера, запустите.
2. В одной LAN узлы найдут друг друга сами. Имя задаётся в поле «Моё имя».
3. Через интернет: у одной из сторон пробросьте на роутере **TCP 45678** (UDP 45677 — опционально, для статуса) и разрешите приложение в брандмауэре. Затем добавьте белый IP собеседника в поле «IP вручную». Пусть первым пишет тот, у кого порт закрыт, — дальше канал двусторонний.

### RDP

Откройте чат с узлом → кнопка **RDP** → запустится mstsc на `127.0.0.1:3390`.
На удалённом ПК должен быть включён «Удалённый рабочий стол» (Windows Pro/Enterprise).

## Порты

| Порт | Протокол | Назначение |
|---|---|---|
| 45677 | UDP | обнаружение узлов (announce/response/bye) |
| 45678 | TCP | сообщения, постоянный канал, туннели |
| 8087 | TCP | push на телефон (ntfy, опционально, выкл по умолчанию) |

Изменяются флагами `--udp-port` / `--tcp-port` (у всех участников должны совпадать).

## Настройки

Кнопка «Настройки» открывает компактное окно с вкладками:

- **Общие** — автозапуск с Windows и тёмная тема
- **Сеть** — принимать из любых сетей (VPN/белый IP), сканер, приём комнат, ручной IP и вход в комнаты
- **Защита** — TLS, сетевой пароль и известные отпечатки узлов
- **RDP** — туннель, совместный сеанс и разрешение Shadow через UAC
- **Уведомления** — ntfy-push, уведомления о версиях, ссылка и текст уведомления; отдельные кнопки «Проверить обновления» и «Показать пример уведомления»

В каждой вкладке содержимое прокручивается по вертикали, а кнопка OK остаётся
видимой внизу окна. Поля растягиваются по ширине, длинные подписи переключателей
переносятся. Значения сохраняются между вкладками и применяются вместе по OK.

Сортировка списка — кнопка над списком: в сети сверху / по имени / по IP.

## Запуск из исходников

```bash
py -3.11 -m pip install -r requirements.txt
py -3.11 main.py            # GUI
py -3.11 main.py --console  # консольный режим
py -3.11 main.py --multi    # второй экземпляр (для тестов)
```

На macOS используйте `python3.11` вместо `py -3.11`. Запуск из исходников хранит
рабочие данные в текущей папке; установленная macOS `.app` — в Application Support.

Сборка Windows exe (перед каждой сборкой поднять `__version__` в `app/__init__.py`):

```bash
py -3.11 -m pip install -r requirements-build.txt
py -3.11 scripts/run_tests.py
powershell -ExecutionPolicy Bypass -File scripts/build_windows.ps1
# результат: dist\LANMessenger.exe
```

Перед пересборкой остановите запущенный exe и сохраните предыдущий рабочий файл отдельно.
Скрипт запускает PyInstaller с очищенным PATH, исключая DLL сторонних приложений.
После сборки проверьте, что приложение запускается. macOS использует собственный
`packaging/macos/LANMessenger.spec` и каталог `dist/macos/`, Windows exe не перезаписывается.

## Тесты

```bash
py -3.11 scripts/run_tests.py
```

Полный набор: `demo_two_nodes.py`, `test_persistent.py`, `test_rooms.py`, `test_crypto.py`,
`test_tls.py`, `test_ui_smoke.py`, `test_legacy_ack.py`, `test_platform_support.py`,
`test_ai.py`, `test_ai_ui.py`, `test_ai_pi.py`. Для последнего нужен установленный Pi;
без него тест явно пропускается. Каждый скрипт запускается

## Структура

```
main.py                  # вход, single-instance, CLI
app/
  core/
    engine.py            # ядро: чаты, настройки, watchdog соединений
    history.py           # SQLite-история (history.db)
    tunnel.py            # проброс портов (RDP) через канал
    push.py              # SSE push-сервер для ntfy
  net/
    protocol.py          # JSON-пакеты LANMSG/1, TCP-фрейминг
    discovery.py         # UDP discovery, реестр узлов, дедупликация
    connections.py       # постоянные TCP-соединения, keepalive
    scanner.py           # сканер подсети (ping/ARP/hostname)
  ui/
    main_window.py       # главное окно (вкладки Чаты/Календарь, колокольчик)
    chat_window.py       # панель чата, пузыри Telegram-стиля, вставка картинок
    calendar_window.py   # календарь: лента событий, диалог события
    image_viewer.py      # выезжающий просмотрщик картинок с зумом
    settings_dialog.py   # настройки и фичефлаги
    theme.py             # светлая/тёмная тема
    switch.py            # виджет-переключатель
```

## Протокол (кратко)

- Discovery: UDP JSON `LANMSG/1` — `announce / response / bye` (+ версия, ссылка и текст обновления)
- Канал: TCP, фрейминг `4 байта длины + JSON` — `hello / msg / ack / ping / stream_* / event_*`
- Туннель: кадры `stream_open / stream_open_ack / stream_data / stream_close` (данные base64)
- Календарь: `event_add / event_delete / event_sync` (tombstones, конфликты по updated_at)
- Фильтр входящих: только приватные IP + явно разрешённые; режим «принимать из любых сетей» — в настройках

## Замечания по безопасности

- TLS включён по умолчанию, отпечатки узлов запоминаются. Общий сетевой пароль добавляет PSK-шифрование личных сообщений, пароль комнаты — шифрование содержимого комнаты.
- RDP-трафик в туннеле шифруется самой Windows (NLA).
- Переписка LAN остаётся между заданными узлами. При включённых уведомлениях о версиях приложение обращается к GitHub без передачи переписки. Установка ИИ загружает компоненты с nodejs.org, GitHub и registry.npmjs.org; запросы агента идут выбранному пользователем провайдеру.

# Changelog — LAN Messenger

Версии до 0.9.1 не нумеровались; вся ранняя история собрана в блок «0.1.0».

## 0.14.1 — 2026-10-03

- ACK теперь уходит только после фактической записи сообщения у получателя: сбой записи → честный «не доставлено» у отправителя вместо ложных галочек.
- Исправлен вылет диалога настроек (недостающий импорт QLabel).

## 0.14.0 — 2026-10-03

- Уведомление о новой версии теперь несёт ссылку и текст от того клиента, который новее (передаются в announce). Ссылка по умолчанию — страница релизов GitHub.
- В настройках: редактируемые ссылка и текст уведомления (шаблон {name} {ver} {my} {url}), свитч «Информационные уведомления», кнопка «Тест уведомления».

## 0.13.1 — 2026-10-03

- Исправлено зависание приложения: панель уведомлений на Qt.Popup модально захватывала ввод и блокировалась диалогами. Панель теперь встроенная, без захвата.
- Панель уведомлений: нормальная высота строк, перенос длинного текста, без горизонтального скролла (0.13.2).
- При запуске новая копия закрывает старые экземпляры по имени процесса (приоритет у новой).

## 0.13.0 — 2026-10-03

- Центр уведомлений: колокольчик справа вверху со счётчиком, панель со ссылками (🔗 открывает в браузере). Туда собираются сообщения, напоминания, ошибки туннеля и алерты о версиях.
- Версия приложения передаётся в announce — узлы видят, у кого что стоит.

## 0.12.3 — 2026-10-03

- Календарь: все события одной лентой с разделителями по датам; клик по дню прокручивает ленту к нему.

## 0.12.2 — 2026-10-03

- Просмотрщик картинок накрывает весь чат; перетаскивание изображения ЛКМ при зуме; исправлено масштабирование панели при развороте окна.

## 0.12.1 — 2026-10-03

- Клик по сообщению с картинкой — выезжающий просмотрщик с зумом (колесо, кнопки, 1:1).

## 0.12.0 — 2026-10-03

- Календарь: раскраска ячеек (чужие месяцы, выходные, сегодня), выделенные строка недель и номера недель, двойной клик по дню создаёт событие.
- Картинки по Ctrl+V прямо в чат (скриншоты), хранятся в images/, переживают перезапуск.
- Чаты с непрочитанными всплывают наверх списка; клик по тосту открывает чат с этим сообщением.
- AGENTS.md с правилами проекта.

## 0.11.1 — 2026-10-03

- Исправлен вылет календаря на Qt6 (`QDateTime(QDate)` убрали из Qt — заменено на `QDate.startOfDay()`).
- Календарь — вкладка главного окна, не отдельное окно.

## 0.11.0 — 2026-10-03

- Календарь: личные и общие события («для всех» или выбранные участники), напоминание за N минут (по умолчанию 15), окно с месяцем и списком дня.
- События рассылаются по каналам мессенджера и догоняют узел при позднем подключении; удаление — tombstone, конфликты по updated_at.
- Напоминания с защитой от дублей (флаг в БД).
- «Тихий режим (до перезапуска)» в меню трея — глушит тосты и звук до перезапуска приложения.

## 0.10.0 — 2026-10-03

- Явная кнопка «Выход» в главном окне — полное завершение процесса с подтверждением (крестик по-прежнему сворачивает в трей).

## 0.9.9 — 2026-10-03

- Жёсткая блокировка второго экземпляра: повторный запуск показывает «уже запущен» и не открывается. Pid-файл и автоубийство старой копии убраны; `--multi` остаётся для тестов.

## 0.9.8 — 2026-10-03

- Совместный сеанс RDP теперь выключен по умолчанию; включается свитчем в настройках.
- Если совместный сеанс не сработал (нет политики Shadow, нет активной сессии, старая версия у собеседника) — открывается обычный RDP, с пояснением причины.

## 0.9.7 — 2026-10-03

- Кнопка «Разрешить совместное подключение на этом ПК» в настройках: прописывает Shadow=2 в реестре через UAC, без ручной работы с regedit.

## 0.9.6 — 2026-10-03

- Теневой режим RDP (mstsc /shadow): подключение к живой сессии пользователя вместо выкидывания её на экран блокировки. Id сессии запрашивается по каналу мессенджера. Требуется политика Shadow на удалённом ПК — иначе понятная ошибка.

## 0.9.5 — 2026-10-03

- Ошибки туннеля показываются в окне: старая версия у собеседника, RDP выключен флагом, порт 3389 не отвечает. Раньше mstsc просто молча не подключался.

## 0.9.4 — 2026-10-03

## 0.9.3 — 2026-10-03

## 0.1.0 — 2026-10-02

MVP и работа над ошибками первого дня боевого тестирования.

Добавлено:

- UDP-discovery в LAN (announce/response/bye), список узлов по IP, статусы в сети/не в сети.
- Личные чаты: TCP-кадры, подтверждение доставки, история в одном файле history.db рядом с exe.
- Постоянные соединения: канал открывает сторона, которая может достучаться, — через интернет достаточно одного проброшенного TCP 45678.
- RDP-туннель по кнопке в чате: mstsc на 127.0.0.1:3390, трафик через канал мессенджера.
- Сканер подсети (ping/ARP/hostname), живые строки по мере находки.
- Трей с уведомлениями при закрытом окне, автозапуск с Windows.
- Настройки с фичефлагами (RDP, сканер, ntfy), тёмная и светлая темы, пузыри сообщений.
- Ручное добавление узла по IP, в т.ч. белому.

Исправлено:

- Ручные пиры и разрешённые IP терялись при перезапуске — переписка через интернет умирала молча. Теперь сохраняются в settings.json.
- Дедлок при одновременном дозвоне с двух сторон: оба соединения закрывались. Решается тай-брейком по node_id.
- Дубли узла при анонсе с нескольких адресов (белый IP + VPN) — одна строка на клиента.
- Прыжки списка узлов: перерисовка только при реальных изменениях, скролл сохраняется.
- Сканер хватал виртуальные адаптеры Docker/WSL и «фантомы» из VPN — фильтр по интерфейсам со шлюзом и по ARP.
- Текст пузырей был невиден в светлой теме при тёмной теме Windows — явный цвет текста.
- Повторный запуск exe теперь закрывает зависший экземпляр и стартует сам (pid-файл + мьютекс).
- Мёртвые узлы удаляются из списка через час.

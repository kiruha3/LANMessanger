# Changelog — LAN Messenger

Версии до 0.9.1 не нумеровались; вся ранняя история собрана в блок «0.1.0».

## 0.19.1 — 2026-10-05

- Полировка интерфейса под макет: в чате разделители дней «— Сегодня — / — Вчера — / — дата —», у исходящих статус текстом «HH:MM · Доставлено / Отправляется / Ошибка» вместо галочек.
- Переключатель «Уведомления» в панели сведений о собеседнике: отключает звук и тосты конкретного чата (счётчик непрочитанных продолжает расти), запоминается в настройках.
- Внизу левой панели строка состояния: «Приложение в сети» / «Нет соединения».
- Левая панель: заголовок «Компьютеры», поле имени стало компактным справа от заголовка.
- Кнопка RDP в заголовке чата — нарисованная иконка-монитор (бирюзовая при активном туннеле), подсказки «Удалённый рабочий стол» / «Закрыть туннель».
- Тёмная тема перекрашена в тёмно-синюю (navy): фон #161a22, панели #1f2630, бирюзовые акценты.

## 0.19.0 — 2026-10-05

- Интерфейс «Рабочее место»: верхняя панель (название, навигация Чаты/Календарь/Помощь, колокольчик и настройки), слева список с поиском по имени, центр — чат, справа сворачиваемая панель сведений (собеседник: статус, канал, RDP; комната: участники и приглашение).
- Акцент бирюзовый (#0d9488), тонкие разделители, светлая и тёмная темы.
- Боковые панели регулируются сплиттером; при ширине окна < 950px панель сведений скрывается автоматически и открывается кнопкой-зажимом.
- Весь прежний функционал сохранён: чаты, комнаты, картинки и просмотрщик, календарь, уведомления, RDP, настройки, трей, фичефлаги, история.

## 0.18.0 — 2026-10-04

- Безопасный дефолт: из фич включён только RDP. Сканер, приём комнат, алерты версий, ручной IP и вход в комнаты — по свитчам в настройках (миграция сохранённых значений не трогает).
- Поля «IP вручную» и «комната@IP-хаба» скрыты по умолчанию, включаются свитчами без перезапуска.
- Вкладка «Помощь» внутри приложения: руководство из 11 раскрывающихся разделов.
- Таблица событий календаря создаётся при инициализации истории (раньше падало при открытии вкладки до старта движка).

## 0.17.0 — 2026-10-04

- TLS-канал между клиентами: автоопределение по первому байту — старые клиенты без TLS продолжают работать. Self-signed сертификат генерируется при старте.
- Пиннинг отпечатка узла (known hosts в настройках + уведомление).
- PSK для P2P: «Сетевой пароль» — личные сообщения и картинки шифруются AES-256-GCM; неверный пароль — строка-предупреждение.
- Группа «Шифрование» в настройках: свитч TLS, поле пароля, список отпечатков.

## 0.16.0 — 2026-10-04

- PSK-комнаты: пароль при входе в комнату, сообщения и картинки шифруются AES-256-GCM (ключ из пароля через PBKDF2). Хаб релеит, не читая — проверено боем: в истории хаба только «не удалось расшифровать».
- Кнопка «Пригласить» в чате комнаты: код `комната:пароль@IP-хаба` для пересылки.
- Метка «[закрытая]» у защищённых комнат.

## 0.15.7 — 2026-10-03

- Join к своей комнате — локальный, без дозвона до себя (раньше хаб звонил сам себе по петле).

## 0.15.6 — 2026-10-03

## 0.15.5 — 2026-10-03

- Ссылка обновлений по умолчанию — прямая на скачивание последнего релиза (releases/latest/download), всегда актуальная, без входа на GitHub.

## 0.15.4 — 2026-10-03

- Один активный RDP-туннель на приложение: новый закрывает старый; кнопка показывает адресата.

## 0.15.3 — 2026-10-03

## 0.15.0 — 2026-10-03

## 0.1.0 — 2026-10-02

MVP и работа над ошибками первого дня боевого тестирования.

Добавлено:

- UDP-discovery в LAN (announce/response/bye), список узлов по IP, статусы в сети/не в сети.
- Личные чаты: TCP-кадры, подтверждение доставки, история в одном файле history.db рядом с exe.
- Постоянные соединения: канал открывает сторона, которая может достучаться, — через интернет достаточно одного проброшенного TCP 45678.
- RDP-туннель по кнопке в чате: mstsc на 127.0.0.1:3390, трафик через канал мессенджера.
- Сканер подсети (ping/ARP/hostname), живые строки по мере находки.
- Трей с уведомлениями при закрытом окне, автозапуск с Windows.
- Настройки с фичефлагами (RDP, сканер, ntfy), тёмная и светлая темы, пузыри сообщений.
- Ручное добавление узла по IP, в т.ч. белому.

Исправлено:

- Ручные пиры и разрешённые IP терялись при перезапуске — переписка через интернет умирала молча. Теперь сохраняются в settings.json.
- Дедлок при одновременном дозвоне с двух сторон: оба соединения закрывались. Решается тай-брейком по node_id.
- Дубли узла при анонсе с нескольких адресов (белый IP + VPN) — одна строка на клиента.
- Прыжки списка узлов: перерисовка только при реальных изменениях, скролл сохраняется.
- Сканер хватал виртуальные адаптеры Docker/WSL и «фантомы» из VPN — фильтр по интерфейсам со шлюзом и по ARP.
- Текст пузырей был невиден в светлой теме при тёмной теме Windows — явный цвет текста.
- Повторный запуск exe теперь закрывает зависший экземпляр и стартует сам (pid-файл + мьютекс).
- Мёртвые узлы удаляются из списка через час.

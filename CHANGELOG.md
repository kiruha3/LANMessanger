# Changelog — LAN Messenger

Версии до 0.9.1 не нумеровались; вся ранняя история собрана в блок «0.1.0».

## 0.24.7 — 2026-11-20

- При переходе по карточке агента свёрнутая ветка раскрывается после обработки клика. Переходы из списка также применяются после обработки выбора строки.

## 0.24.6 — 2026-11-20

- Список ИИ-чатов не сдвигается при переключении между чатами со связями и без них. Стрелки рисуются в узком желобке слева.

## 0.24.5 — 2026-11-20

- Новые дочерние чаты агентов вложены под исходным чатом. В списке видны до трёх связей выбранного чата и запросы, по которым ещё ждут ответа. Из карточек можно перейти к связанному сообщению; связи сохраняются после перезапуска.

## 0.24.4 — 2026-11-19

- «Уточнить сейчас» и «В очередь» теперь на компактной плашке над полем ввода. Стрелка отправки остаётся на месте.

## 0.24.3 — 2026-11-19

- Во время работы ИИ можно поставить новое сообщение «В очередь» до конца задачи или нажать «Уточнить сейчас». Уточнение прерывает поток ответа, сохраняет написанный текст и отправляется в том же чате. Уже запущенный инструмент завершается перед уточнением.

## 0.24.2 — 2026-11-19

- Стрелка отправки остаётся на месте, когда агент начинает отвечать. Новое дополнение сразу появляется в чате с пометкой «В очереди», пока агент не получит его.

## 0.24.1 — 2026-11-19

- Основная сборка Windows включает каталог плагинов, инструменты чата и отправку дополнений работающему агенту.

## 0.24.0 — 2026-11-19

- Во вкладке «Плагины» появились встроенные инструменты ИИ. Их можно включать отдельно для каждого чата через кнопку «Инструменты» возле поля ввода.
- Карточка генерации в переписке показывает состояние задания и открывает дочерний чат с результатом. Ручная генерация не зависит от переключателя агента.
- Работающему текстовому агенту можно отправить новое текстовое дополнение, не останавливая его и не меняя предыдущие сообщения.

## 0.23.2 — 2026-11-18

- В настройках ИИ API-ключ можно показать, скопировать и снова скрыть кнопкой рядом с полем. При смене аккаунта или провайдера и закрытии настроек ключ снова скрывается. Способ хранения ключей не меняется.

## 0.23.1 — 2026-11-18

- ИИ-чаты можно закреплять и откреплять правым кликом. Внутри каждой папки закреплённые выше остальных; выбор сохраняется после перезапуска. Индикатор работы остаётся видимым рядом со значком закрепления.
- Пакетная генерация Horde соблюдает ограничение частоты: новые задания отправляются с небольшим интервалом, без ожидания готовности других картинок. Ошибки сервиса не запускают автоматические повторы.
- Неожиданная ошибка обработчика ИИ прерывает затронутую задачу и отображается в её чате; диагностический traceback с удалёнными ключами сохраняется в ai-data/errors.log. Другие чаты продолжают работать.

## 0.23.0 — 2026-11-18

- При полном выходе приложение отправляет отмену всех заданий AI Horde, включая дочерние и сохранённые очереди, и до пяти секунд ждёт подтверждения сервиса. Подтверждённые отмены не предлагаются как работающие задания после запуска; при ошибке ID сохраняется для проверки. Сворачивание в трей оставляет генерации работающими. Синхронные Images API могут продолжить работу на сервере.
- Текстовый агент получает статус очереди Horde до готовности картинки: место, оценку ожидания в секундах и время проверки. Он может проверить состояние снова и отменить свои генерации по условию пользователя; произвольный лимит ожидания не задаётся.
- По просьбе пользователя агент может задать вопрос существующему свободному ИИ-чату либо создать отдельный чат с выбранным аккаунтом и моделью и получить ответ. Переписка видна в списке; занятые чаты и чаты с черновиками защищены от чужого запроса. Остановка исходного агента останавливает ожидаемые им задачи; вложенность ограничена двумя уровнями.
- ИИ-чаты в папках сортируются по последнему сообщению: новые сообщения и результаты поднимают чат вверх, давние остаются внизу. Порядок сохраняется после перезапуска; просмотр без сообщений его не меняет.
- ИИ-чаты работают параллельно: переход в другой чат и запуск новой задачи не прерывают предыдущую. У каждого чата свой процесс, модель, очередь картинок, черновик и остановка; выполняющиеся задачи отмечены в списке.
- Текстовый агент может вызвать модель картинок через generate_image: по умолчанию бесплатный AI Horde, другой настроенный аккаунт и модель — по запросу. До четырёх разных моделей запускаются параллельно, без ожидания первой картинки перед отправкой следующей. Для каждой модели создаётся дочерний чат, результаты с названием модели возвращаются в исходную переписку по мере готовности; ошибка или остановка одной не мешает остальным. Остановка исходного агента отменяет все его ожидающие генерации. По запросу доступны поиск и чтение других ИИ-чатов, без доступа к личным сообщениям мессенджера.
- В настройках каждого текстового аккаунта появился раздел «Инструмент image gen»: можно выбрать аккаунт картинок и модель для запросов через агента, в том числе сменить провайдера. Настройки сохраняются отдельно и применяются к следующей задаче; URL и ключ хранятся в аккаунте картинок. При ошибке сервис автоматически не меняется, недоступное подключение сопровождается инструкцией по настройке.
- Агент может самостоятельно получить список моделей картинок через list_image_models. Для AI Horde загружаются модели с активными исполнителями, для совместимого Images API — каталог и ограничения доступа. Если доступен только сохранённый список, агент видит предупреждение, что он мог устареть.
- В списке ИИ-чатов пульсирует индикатор работающей задачи. Чаты с новыми готовыми результатами подсвечены до открытия, ошибки отмечены отдельно, неактивные чаты показаны серым. Непросмотренные результаты сохраняют отметку после перезапуска.
- Картинки можно вставлять в ИИ-чат через Ctrl+V, перетаскивание или кнопку «+». Вложения показываются в переписке и передаются модели; WebP подготавливается как PNG. Исправлено объявление совместимого API только текстовым: изображения из read и результатов генерации больше не отбрасываются до отправки. Сам выбранный API и модель должны поддерживать изображения.
- Каждый чат ИИ запоминает свой аккаунт и последнюю выбранную модель: они восстанавливаются при переходе между чатами и после перезапуска. Новый чат начинает с текущего выбора; старые чаты сохраняют выбор при первом открытии.
- Бесплатное подключение AI Horde с моделью Dreamshaper включено в базовую конфигурацию и добавляется при обновлении автоматически. В новом чате кнопка «Нарисовать бесплатно — AI Horde» сразу выбирает его; ключ, регистрация и предварительная загрузка моделей не требуются. Прежние настройки и выбранный аккаунт сохраняются; существующее подключение Horde не дублируется.
- В чате ИИ можно получать картинки: AI Horde без регистрации с бесплатной очередью, Cloudflare FLUX.1 Schnell с дневной квотой и совместимые Images API, включая Provod. Готовая картинка видна в ленте, сохраняется в истории; доступны открытие, копирование и сохранение. Задание Horde можно получить после перезапуска по сохранённому ID без повторной генерации.
- В обычных личных чатах и комнатах можно выделять фрагмент сообщения мышью и копировать его через Ctrl+C (Cmd+C на macOS) или «Копировать выделенное» в контекстном меню. Двойной щелчок выделяет слово. Выделение сохраняется при обновлении статуса сообщения.
- Справа внизу поля сообщения ИИ — выбор модели и шестерёнка настроек. В настройках собраны аккаунты, подключение, модели, размышления, инструкции и компоненты ИИ. У каждого аккаунта свои провайдер, URL, модель, инструкции, API-ключ и вход Pi; их можно переключать и переименовывать. Прежнее подключение сохранено как «Основной» без переноса ключей и истории.
- Поле сообщения начинается с одной строки и растёт вместе с текстом до шести строк. В ленте во время задачи показано текущее действие агента; кнопка отправки меняется на квадрат остановки; новые сообщения и потоковый ответ прокручивают чат вниз.
- Через «Добавить папку…», путь внизу поля сообщения или настройки можно выбрать рабочую папку проекта. Слева папки объединяют чаты и показывают их количество. Выбор чата переключает папку агента; последний открытый чат восстанавливается после перезапуска. Для недоступной папки история остаётся доступна для чтения.
- При ошибке модели, ключа, доступа или соединения появляется инструкция, что проверить, и кнопка открытия настроек. Исходная причина ошибки сохраняется; автоматической повторной отправки нет.
- Запуск ИИ больше не устанавливает пакеты из настроек Pi в рабочей папке. Автоматическая загрузка расширений, skills и шаблонов отключена; поддержка HTTP(S)-прокси сохранена.
- Отключённый или очищенный ключ не восстанавливается из сохранённой копии или окружения процесса. Списки моделей и настройки каждого аккаунта восстанавливаются после перезапуска.
- При потере сессии Pi видимая переписка сохраняется с отметкой о новом контексте. Ошибка провайдера отображается как ошибка задачи, а не успешное завершение. Повреждённый файл состояния не перезаписывается и не обрушает окно.
- Отмена установки проверяется между короткими чтениями загрузки; закрытие приложения ограниченно ждёт остановки установщика.

## 0.22.13 — 2026-11-13

- Исправлена ошибка `CERTIFICATE_VERIFY_FAILED` при установке ИИ на другом Windows-ПК: в exe включён набор корневых сертификатов, HTTPS использует также системную проверку цепочки Windows. Проверка сертификата и имени сервера остаётся включённой. Приватные Node.js и npm используют доверенные сертификаты Windows.
- Над чатом ИИ добавлены режимы «С пояснениями» и «Без пояснений». Кнопка «Инструкция…» открывает редактирование инструкции выбранного режима, с сохранением, отменой и возвратом стандартного текста. Выбор и обе инструкции сохраняются; применяются к следующей задаче. Карточки действий и полученный потоковый текст остаются видимыми в обоих режимах.

## 0.22.11 — 2026-11-13

- На Windows x64 вкладка ИИ предлагает установить нужные компоненты одной кнопкой: Node.js, Pi, Git Bash и поиск по файлам. Загрузка, проверка файлов и настройка выполняются внутри приложения с прогрессом, отменой и повторной попыткой; отдельная установка программ и права администратора не нужны.
- Добавлена проверка стабильных Windows-релизов на GitHub после запуска и каждые 6 часов, а также кнопка «Проверить обновления» в настройках. Для новых установок уведомления включены; сохранённое отключение остаётся в силе. Старые exe, знающие только версии узлов LAN, нужно обновить вручную один раз.
- Новая иконка: белые буквы LM в синем квадрате. В трее видна красная отметка непрочитанных сообщений и уведомлений, в подсказке — отдельные счётчики. Уведомления о тех же сообщениях не удваивают число.
- В «Настройки → Уведомления» добавлена галочка «Открывать мессенджер при новом сообщении». Она восстанавливает окно из трея или свёрнутого состояния и открывает нужный чат. По умолчанию выключена; тихий режим и отключённые уведомления чата учитываются.

## 0.22.7 — 2026-11-13

- В пустом чате ИИ показаны шаги подключения URL, собственного API-ключа и модели. Ниже — раскрываемые разделы справочника из 28 моделей с ценами и ориентирами по применению. После первого сообщения подсказка скрывается; в новом чате появляется снова.
- «Загрузить модели» для совместимого API получает точные ID и группы из указанного URL с вашим ключом. При ошибке ID можно ввести вручную; изменение URL или ключа отменяет старую загрузку. Справочные названия не подставляются вместо API ID.
- Добавлен сохраняемый выбор уровня размышлений: авто, выключены, минимальный, низкий, средний, высокий и очень высокий. Настройка передаётся Pi; фактический уровень показан в подключении и зависит от модели. Для совместимого API явный выбор передаётся как `reasoning_effort`, если сервер его поддерживает.

## 0.22.1 — 2026-11-13

- Добавлена вкладка «ИИ»: локальный агент Pi с потоковым ответом, отображением действий, остановкой и отдельной историей чатов.
- Агент автоматически работает в папке рядом с exe; при запуске из исходников — в текущей папке. Он может читать и менять файлы и выполнять команды с правами пользователя.
- Подключение модели находится во вкладке: API-ключи OpenAI, Anthropic, Google и совместимых серверов; вход по аккаунту через поддерживаемые Pi OAuth-провайдеры. Ключ можно сохранить в Windows через DPAPI; без сохранения он остаётся в памяти.
- Для ИИ нужны отдельно установленные Node.js, Pi и Git Bash на Windows. LAN-чаты и хаб работают без этих зависимостей. Содержимое задачи и прочитанные агентом данные передаются выбранному провайдеру; LAN-переписка автоматически не добавляется.
- Агентские сессии восстанавливаются из Pi перед продолжением; прерванные запросы не отправляются повторно автоматически. Автоматические повторы и сжатие контекста Pi отключены в первой версии.
- Windows-сборка использует очищенный PATH, чтобы посторонние DLL из среды разработки не мешали запуску Qt. Первая локальная сборка 0.22.0 заменена проверяемой сборкой 0.22.1.

## 0.21.0 — 2026-10-20

- Опубликованы [экспериментальные Mac-сборки для Apple Silicon и Intel](https://github.com/kiruha3/LANMessanger/releases/tag/v0.21.0-macos); архивы доступны в Releases. Windows 0.20.0 остаётся стабильным релизом с прежней ссылкой на exe.
- Подготовлена отдельная экспериментальная сборка для macOS: приложение `.app` и архивы для Apple Silicon и Intel. Ручной сценарий GitHub Actions сначала проверяет Windows, затем запускает полный набор тестов, сборку и проверку старта на macOS; релиз автоматически не публикуется.
- В macOS-приложении история, настройки, изображения и TLS-сертификат хранятся в `~/Library/Application Support/LANMessenger`, чтобы обновление `.app` не затрагивало данные. В Windows файлы по-прежнему лежат рядом с exe.

# План: дефолты «всё выключено, кроме RDP» + скрытие сетевых полей + руководство

## Цель

Чистый старт для обычного пользователя: работает чат в LAN и RDP. Всё
продвинутое — по свитчам в настройках.

## Шаг 1. Дефолты флагов (engine.py)

| Флаг | Было | Станет |
|---|---|---|
| rdp_enabled | вкл | вкл (единственный) |
| scan_enabled (сканер сети) | вкл | выкл |
| hub_enabled (принимать комнаты) | вкл | выкл |
| notify_update (алерты о версиях) | вкл | выкл |
| shadow_rdp, push, network_psk | выкл | выкл (как было) |

TLS остаётся включённым — это не фича, а транспортная безопасность.

Миграция: у существующих установок сохранённые значения в settings.json
остаются как есть (дефолты — только для новых).

Тесты: test_rooms.py, test_crypto.py и др. хостят комнаты — выставлять
hub_enabled=True явно в тестах.

## Шаг 2. Скрытие полей добавления по IP и комнаты@IP

- Новые флаги: `manual_ip_enabled`, `room_join_enabled` (дефолт выкл).
- Левая панель: строки «IP вручную» и «комната@IP-хаба» видны только при
  включённых флагах. Дерево узлов/комнат не трогаем.
- Настройки → Функции: свитчи «Ручное добавление по IP» и «Вход в комнаты
  (комната@IP)». Включение показывает поля без перезапуска (refresh).

## Шаг 3. Руководство пользователя (РУКОВОДСТВО.md)

Разделы: установка/перенос; чат в LAN; через интернет (проброс порта,
белый IP); ручной IP; комнаты и хаб (свой комп как хаб, сервер,
пароли, приглашения); RDP (обычный и совместный сеанс, требования);
картинки Ctrl+V и просмотрщик; календарь и напоминания; уведомления
(тосты, колокольчик, тихий режим); настройки и все свитчи; шифрование
(TLS, PSK, пароли комнат); сканер сети; ntfy на телефон; порты;
устранение проблем (таблица симптом→причина→действие).

## Шаг 4. Проверка и сборка

- Все тесты зелёные (после правки дефолтов в тестах).
- Smoke: свежий профиль — панели IP/комнат скрыты, включаются свитчами.
- Версия 0.18.0, exe, коммит. Без пуша (по правилу).

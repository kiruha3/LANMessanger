# Установка компонентов ИИ и проверка релизов

**Цель:** пользователь получает один exe и устанавливает зависимости из вкладки ИИ одной кнопкой.
**Решение:** загрузка официальных portable Node.js и Git Bash с закреплёнными SHA256, установка Pi 0.73.1 через приватный npm без install scripts. Компоненты размещаются в LOCALAPPDATA/LANMessenger; системный PATH и права администратора не нужны. Фоновый поток, прогресс, отмена, staging и проверка до активации. Системные установки сохраняются как запасной вариант.
**Альтернативы:** полный архив увеличивает первоначальную загрузку; отдельный runtime-asset требует публикации до использования. Прямая загрузка upstream позволяет проверить всё локально до релиза. Выбор UX — пользователь; способ загрузки — решение реализации.
**Обновления:** сейчас только UDP-анонсы и выключенный флаг. Добавить GitHub stable Windows-релизы в отдельном потоке, раз в 6 часов и по кнопке. Сохранённое отключение уважать; новые установки включены. Уже выпущенные exe требуют ручного обновления.

- [x] Тесты загрузки, SHA256, безопасной распаковки, отмены, приватного runtime и UI.
- [x] Установщик, runtime discovery, окружение агента и авторизации, предложение в ИИ.
- [x] Тесты и исправление проверки обновлений, отдельная кнопка реальной проверки.
- [x] Документация, CHANGELOG, полная проверка, версия 0.22.11, локальная сборка и запуск.

Дополнения пользователя: иконка LM в простом синем квадрате, отметка непрочитанных
в трее; опциональное восстановление окна при новом сообщении по галочке в настройках
уведомлений. Галочка выключена по умолчанию, сохраняется, учитывает мьют и тихий
режим; уже открытое окно не переключает текущий чат. Проверка — сохранение настройки,
скрытое/свёрнутое/открытое окно, тихий режим и мьют.

Не публиковать без новой команды. Не трогать пользовательские ключи, настройки и историю. Проверить реальный Pi с приватными Node и Bash при очищенном PATH, загрузку из интернета, повторный запуск и ошибки сети. Установщик не отправляет отложенные сообщения автоматически.

Проверено: реальные upstream-загрузки и установка в build/clean-ai-runtime;
два интеграционных теста Pi при PATH только System32 — запись файла, Bash, Git,
rg, fd и восстановление сессии. Полный набор 16 скриптов зелёный
(build/release-0.22.11-tests.log), PyInstaller успешно собрал 0.22.11
(build/release-0.22.11-build.log). Независимая проверка: блокирующих замечаний нет;
исправлены восстановление backup, предложение ремонта и блокировка управления
агентом во время установки. Предыдущие exe сохранены в dist/windows-preserved.

# Подключение и каталог в пустом чате ИИ

Пользователь просит показывать инструкцию сверху первого/нового чата до первого
сообщения: указать URL, самостоятельно ввести ключ, выбрать модель. Модели по
возможности загружать по URL и ключу. Кнопки получения ключа нет.

В общей прокручиваемой области ленты показывается приветственный блок с кнопкой
открытия подключения. После первого пользовательского сообщения он скрывается;
в новом пустом чате снова появляется. Это справочный интерфейс, он не записывается
в историю и не отправляется провайдеру. Поле ввода задачи остаётся доступным.

Каталог содержит все 28 строк листа «Тарифы» из предоставленного
`catalog-tariffs.xlsx`. Разделы: OpenAI, Anthropic, Google, изображения Google и
xAI. Разделы раскрываются без внутренних скроллов. Название модели, вход, кеш и
выход сохраняются точно; цены показаны в ₽ за миллион токенов как снимок каталога.
К каждой модели добавляется краткий ориентир по применению, без обещаний
результата или доступности. Модели изображений — справочный раздел: текущий
агентский чат не реализует генерацию изображений. Названия из прайса не считаются
точными API ID и автоматически в запросы не подставляются.

Для «Совместимого API» кнопка «Загрузить модели» выполняет асинхронный
GET `<URL>/models`, передавая ключ в Authorization: Bearer. Используется
пользовательский URL с HTTP(S), например `https://server/v1`. Ключ не попадает
в URL, сообщения об ошибках или логи. Redirect не выполняется; неудача загрузки
сохраняет возможность ручного ввода. Ответ OpenAI `data[].id`, необязательный
`owned_by`; список группируется по владельцу, точные ID сохраняются.

При изменении URL/ключа/провайдера незавершённая загрузка отменяется, старый список
совместимого API сбрасывается. Таймаут 15 секунд, ограничение ответа 2 МиБ.
Для встроенных провайдеров и аккаунтов сохраняется каталог Pi.

Нативные PyQt-виджеты и QtNetwork; новых внешних зависимостей нет. Хранимое
подключение, OAuth, локальный Pi, сессии, Enter и общая прокрутка остаются.
Обновить документацию, поднять версию перед сборкой, прогнать весь набор,
собрать/запустить exe; не пушить.

Дополнение пользователя: выбор уровня размышлений, в том числе высокий и очень
высокий. Сохранять auto/off/minimal/low/medium/high/xhigh; передавать явный выбор
через --thinking и показывать фактический thinkingLevel из get_state Pi. Для
custom API явно включать reasoning и mapping xhigh/none; Auto не добавляет
reasoning_effort. Список /models не даёт стандартных данных о поддержке параметра.

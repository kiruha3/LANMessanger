# Сценарий демо: «LAN Messenger — как доставляется сообщение»

Файл: `lan-messenger-demo.html` (один автономный HTML, работает без сети).
Формат: интерактивная сцена 1600×900, 9 шагов, управляется выступающим
(стрелки / пробел / свайпы, `#step=N` в URL, светлая и тёмная темы).

Сюжет: один сквозной пример — Аня пишет Борису. Сначала оба в локальной сети
(прямой P2P-канал), затем Борис «за NAT» и то же сообщение идёт через хаб-комнату.

## Объекты сцены (одни и те же DOM-узлы на всех шагах)

| Объект | Силуэт | Роль |
|---|---|---|
| `pcA` / `pcB` | ноутбуки (иконка монитора), синий / золотой | узлы Ани и Бориса |
| `hub` | сервер с «рейками», фиолетовый | релей комнат |
| `msg` | конверт, зелёный | зашифрованное сообщение (AES-256-GCM) |
| `lock` | бейдж с замком, красный | TLS + пиннинг / ключ комнаты |

## Шаги

| # | Название | Смысл | Движение |
|---|---|---|---|
| 1 | Два компьютера в сети | Оба запустили один и тот же exe | ноутбуки входят по очереди |
| 2 | Обнаружение по UDP | announce в broadcast (UDP 45677) | дорисовывается связь, бегут пакеты |
| 3 | Прямой канал TCP + TLS | постоянный канал 45678, пиннинг отпечатка | появляется замок на канале |
| 4 | Сообщение напрямую | P2P без посредников, ACK о доставке | конверт летит Аня → Борис |
| 5 | А если друг за NAT? | прямого пути нет — оба идут на хаб, в комнату | прямое ребро гаснет, появляются хаб и дуги |
| 6 | Реле: клиент → хаб | хаб видит только шифротекст | конверт летит к хабу |
| 7 | Реле: хаб → участники | Борис расшифровывает ключом комнаты | конверт летит к Борису |
| 8 | Приближаем шифрование | ключ знают только участники, релей читать не может | камера zoom 1.15 на хаб, замок под хабом |
| 9 | Вся схема целиком | LAN — напрямую, интернет — через хаб; один exe | камера возвращается, видны оба пути |

## Проверки (пройдены)

- `validate_deck.py` — PASS (структура, автономность, без внешних ресурсов).
- Прогон в headless Chromium: скриншоты всех шагов + середина полётов конверта,
  светлая тема, состояние `presentation.state` после 8 переходов — без JS-ошибок.
- Независимое визуальное ревью (отдельный агент): 4 дефекта P1 и 2 P2 найдены
  и исправлены, повторная приёмка — все закрыты, регрессий нет.
- Оставленные допущения (не дефекты): конверт летит по прямой над линией канала,
  broadcast на шаге 2 показан одной линией точка-точка.
